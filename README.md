# Untapped Studio — Niche Finder & Feed Builder

A responsive, browser-based prototype for creators to explore promising video niches, save favorites, and generate a personalized feed of video prompts. The original visual identity and content are used rather than copying the reference website.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. Google Fonts are optional; the interface has system fallbacks.

## Included features

- Search niche ideas by title, category, description, or tags.
- Filter by category and supported platform.
- Sort by opportunity score or show a shuffled set of ideas.
- Browse niche cards with directional interest, competition, and opportunity indicators.
- Save niches and add them to a feed; state persists in browser `localStorage`.
- Generate a video hook and outline, then copy it or add the niche to your feed.
- Responsive navigation and layout for mobile and desktop.

## Prototype data note

Niche signals and opportunity scores are illustrative sample data for the interface, not live platform analytics. Production analytics, accounts, synchronized feeds, and trend integrations require trusted data sources and a backend.
